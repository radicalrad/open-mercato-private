## 7. Why DARAA-34 was opened

  The Hermes/terminal render layer masks the YAML default-value string
  '-open_mercato' as '***' in any output that displays it. The broken
  pattern '${POSTGRES_USER:***@...' visible in read_file / grep / sed /
  git show output is NOT a real bug -- it is the string
  '${POSTGRES_USER:-open_mercato}:${POSTGRES_PASSWORD}@...' with the
  default value redacted for display. Inspect the file with `od -c`
  to confirm.
